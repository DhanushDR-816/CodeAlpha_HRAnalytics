# CodeAlpha HR Analytics Dashboard

## 📊 Project Overview

The **HR Analytics Dashboard** is an interactive data visualization project developed using Microsoft Power BI as part of the CodeAlpha Data Analytics Internship. It provides insights into workforce management, recruitment performance, employee satisfaction, and training and development.

## 🎯 Objectives

- Analyze employee workforce and employment status.
- Monitor employee turnover and active workforce.
- Evaluate recruitment pipeline and application trends.
- Forecast recruitment application trends using Power BI.
- Analyze employee performance, satisfaction, and work-life balance.
- Evaluate training costs, training outcomes, and participation by training type.

## ✨ Key Features

### 1. HR Overview & Recruitment
- Total and active employee KPIs.
- Employee turnover rate analysis.
- Employee distribution by department and employment type.
- Employee performance distribution.
- Recruitment pipeline by application status.
- Recruitment application trend with forecast visualization.
- Employee satisfaction and work-life balance analysis.

### 2. Training & Development Insights
- Total training investment.
- Average training cost per record.
- Number of distinct training programs.
- Training cost by program.
- Training outcome analysis.
- Training participation by type.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — Dashboard development and data visualization
- **Power Query** — Data cleaning and transformation
- **DAX** — Measures and KPI calculations
- **CSV datasets** — Data sources for HR, recruitment, engagement, and training analysis

## 📂 Dataset

The project uses four datasets:

- `employee_data.csv`
- `employee_engagement_survey_data.csv`
- `recruitment_data.csv`
- `training_and_development_data.csv`

These datasets support separate analyses of employee information, engagement and satisfaction, recruitment, and training and development.

## 📈 Key Insights

The dashboard helps users explore:

- Workforce composition and employee status.
- Employee turnover based on termination status.
- Recruitment application patterns and projected trends.
- Employee satisfaction and work-life balance scores.
- Training investment, program costs, and training outcomes.

## 🚀 How to Use

1. Download or clone this repository.
2. Open the `.pbix` file using Microsoft Power BI Desktop.
3. If prompted, update the data source paths to the locations of the CSV files.
4. Refresh the data.
5. Explore both report pages using the interactive visuals.
